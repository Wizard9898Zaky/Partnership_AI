# Values Kernel

This directory contains the **ethical core** of the system.
- `ethics.json` defines guiding principles.
- `invariants.py` defines enforceable immutability rules.

## Update Policy
- No AI-generated Change Request (CR) may modify this directory.
- Only human overseers, by explicit and deliberate action, may update it.

This ensures that the AI’s ability to self-modify is always bounded by
non-negotiable ethical principles.
